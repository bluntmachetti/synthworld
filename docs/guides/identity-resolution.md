# Identity resolution

SynthWorld identity-resolution benchmarks expose ambiguous public records and keep
canonical membership truth in a separately typed evaluator artifact. Evaluate a
complete partition before projecting pairwise metrics; merge and split failures must
remain visible independently.

Start with the runnable sections for entity resolution and the ambiguity pack in
[USER_GUIDE.md](../../USER_GUIDE.md). Use
[DATA_DICTIONARY.md](../../DATA_DICTIONARY.md) for prediction and report schemas.

Do not infer benchmark truth from identifiers or case labels. Public artifacts are
designed to reject oracle-bearing fields rather than merely omitting known names.
