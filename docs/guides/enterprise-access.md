# Enterprise identity and access

The enterprise surface compiles a private structural import into separately typed
public product input and evaluator truth, then supports independent identity-fabric,
agentic, contextual, governance, and assurance contracts.

Start with the author/validate/compile walkthrough in
[USER_GUIDE.md](../../USER_GUIDE.md#use-case-11-enterprise-identity-and-access-structure).
The [enterprise identity/access contract](../../enterprise-identity-access-contract/README.md)
is normative for schemas, budgets, output layout, and limitations.

Importing structure is not anonymization. Keep source imports and namespace salts
private. Shipped evaluator fixtures are public conformance truth, not held-out tests.
