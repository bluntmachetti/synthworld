# Safety boundary

SynthWorld creates safely fictional data; it does not anonymize real data.

- Use reserved domains, fictional phone ranges, example addresses, invalid
  identifiers, and recursive `synthetic: true` markers.
- Never generate reusable credential material.
- Never submit real personal data, secrets, or plausibly real identifiers to public
  issues, discussions, fixtures, or examples.
- Keep private imports, salts, keys, product output, and local receipts outside the
  repository and distribution.

Report real-data emission, leaked secrets, or public oracle leakage through the
[private vulnerability route](https://github.com/bluntmachetti/synthworld/security/advisories/new).
