# Support

SynthWorld is an open-source project and does not promise a support SLA.

| Need | Route |
|---|---|
| Usage or design question | [GitHub Discussions](https://github.com/bluntmachetti/synthworld/discussions/categories/q-a) |
| Reproducible defect or scoped proposal | [GitHub Issues](https://github.com/bluntmachetti/synthworld/issues/new/choose) |
| Documentation contribution | [Documentation contribution guide](contributing-documentation.md) |
| Real-data emission, leaked secret, or oracle leakage | [Private vulnerability report](https://github.com/bluntmachetti/synthworld/security/advisories/new) |

Never post real personal data, secrets, or plausibly real identifiers in a public
support route.
