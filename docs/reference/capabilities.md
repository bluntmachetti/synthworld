# Capabilities

> **Dependency notice.** Validated capability metadata is being integrated by the
> prerequisite governance work and is not yet present on this branch's `main` base.

This page intentionally publishes no hand-maintained status table. Once the
prerequisite lands, `docs/_data/capabilities.resolved.json` becomes the
machine-readable source generated from code-derived facts plus curated claims and
checked for drift.

Capability maturity does not imply benchmark publication, external availability, or
a production support promise. Future renderer integration may present resolved data,
but must not create another hand-maintained status table.
